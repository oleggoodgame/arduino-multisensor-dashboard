# arduino-multisensor-dashboard

This is a multifunctional interactive Arduino-based system that integrates an ultrasonic distance sensor (HC-SR04), a photoresistor, a 16x2 LCD display, LED indicators, and an IR remote control. The system measures distance and ambient light levels in real time, displays data on the screen, controls yellow LED brightness, and can automatically stop (switch to a safe halted state via a button or remote) if an object gets closer than a critical threshold.
